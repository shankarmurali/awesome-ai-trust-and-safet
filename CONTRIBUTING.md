# Contributing

Thanks for helping curate this list. The bar for every entry:

**Would a working practitioner in AI security, fraud, or trust & safety bookmark this?**

## How to suggest an entry

Open a pull request editing `README.md`:

1. Add your entry to the most fitting existing section (propose a new section only
   if 3+ entries would live in it).
2. Format: `[Name](https://link) — One line: what it is and why a defender uses it.`
3. Keep alphabetical-ish / importance ordering consistent with the section.

## What gets merged

- Working, non-paywalled links (canonical paywalled resources allowed if truly essential)
- Tools, research, feeds, and communities with real practitioner value
- Neutral descriptions — no marketing language

## What doesn't

- Product pitches or vendor self-promotion without standalone free value
- Exploit code or offensive tooling without a defensive purpose
- Dead links, personal branding exercises, listicles-of-listicles

One PR per suggestion keeps review easy. Maintainers may edit descriptions for
consistency.
